# Виджет банковских операций
Проект предназначен для обработки данных о банковских операциях.

## Тестирование

Для запуска тестов используется pytest

## Декоратор log

В проект добавлен декоратор "log", который позволяет автоматически записывать информацию о выполнении функций.

Декоратор поддерживает два режима работы.

Если имя файла не указано, информация выводится в консоль.


## Генераторы

В проекте реализованы следующие функции-генераторы:
- 'filter_by_currency' - фильтрует транзакции по коду валюты.
- 'transaction_descriptions' - последовательно возвращает описания транзакций.
- 'card_number_generator' - генерирует номера банковских карт в формате 'XXXX XXXX XXXX XXXX' в заданном диапазоне.

## Работа с JSON
Функция read_json_file() находится в src/utils.py. 
Она загружает список финансовых операций из JSON-файла. 
Если файл отсутствует, пустой, содержит некорректный JSON или корневой элемент JSON не является списком, функция возвращает [].

## Конвертация валют
Функция convert_to_rub() находится в src/external_api.py. 
Для операций в RUB API не вызывается.
Для других валют используется Exchange Rates Data API.

API-ключ хранится в переменной окружения EXCHANGE_RATES_API_KEY.

## Переменные окружения
Для работы программы необходимо создать .env:

EXCHANGE_RATES_API_KEY=your_api_key

Файл .env не загружается в GitHub. 
В репозитории хранится .env.template.

## Функции

### filter_by_state

Фильтрует список банковских операций по значеню ключа 'state'.

По умолчанию используется статус 'EXECUTED'.

Пример:

```python
filter_by_state(operations)
filter_by_state(operations, "CANCELED")
